# Negócio na Área - Web

Painel administrativo desenvolvido para empresas cadastrarem produtos, acompanharem métricas e administrarem suas informações.

## Funcionalidades

- Login de empresas
- Dashboard
- Cadastro de produtos
- Edição de produtos
- Promoções
- Relatórios em PDF
- Analytics
- Perfil da empresa

## Tecnologias

- HTML
- CSS
- JavaScript
- Fetch API

## Instalação

```bash
git clone https://github.com/ZLTech2/Negocio_Area_Front.git

cd Negocio_Area_Front
```
link:

https://negocio-area-web.vercel.app/

## Backend

A aplicação consome a API desenvolvida em Spring Boot.
